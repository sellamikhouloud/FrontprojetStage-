## Description composants 
card2 : composant de la carte d'une famille utilisé dans la version Mobile ainsi que dans le pop-up MAS des visites en retard sur la version Web.

Card : composant de la carte d'une famille utilisé pour afficher les informations des familles.

AlertCard : composant qui contient les différents types d'alertes pouvant être affichés.

Button : composant contient tout les modeles de boutton existe dans les pages .

Navigation : pour naviger entre les pages le "suivant" et le " back " 

Options : liste des options affichées lors de la saisie dans le Choice Container.

PageHeader : : composant d'en-tête de page permettant d'afficher un bouton de retour, un titre principal et une action optionnelle à droite par example Annuler et voir historique ou bien Annuler seulement . 

AfficherContainer : composant conteneur utilisé pour afficher des informations ou des données.

Badge : composant permettant d'afficher les différents statuts dans les cartes.

FilterTag : composant permettant d'afficher un filtre sélectionné sous forme d'étiquette, avec un bouton de suppression pour le retirer.

Textarea : c'est un container pour ecrire .

AlertBox : composant permettant d'afficher différents types d'alertes (succès, information, avertissement) avec un style adapté à chaque variante.

ContainerEcriture : composant conteneur contenant un champ de saisie texte, utilisé pour les formulaires et pouvant être affiché en mode normal ou en mode pointillé (dashed).

ChoiceContainer : composant conteneur permettant de sélectionner une valeur parmi une liste d'options.

DateContainer : composant conteneur dédié à la saisie ou à la sélection d'une date.

ImagePreview : composant permettant d'afficher un aperçu d'une image avec un bouton d'action configurable (Changer, Validée, Refusée).

PopupPhoto : composant popup permettant d'ajouter une photo en choisissant entre prendre une photo ou en sélectionner une depuis l'appareil.

AjouterPhoto : composant popup permettant d'ajouter une nouvelle photo avec ses informations (titre, village, date, description).

ConsulterPhoto : composant popup permettant de consulter les informations d'une photo ainsi que son statut.

ModifierPhoto : composant popup permettant de modifier les informations d'une photo existante.

PhotoRefuse : composant popup permettant d'afficher une photo refusée ainsi que le motif du refus.

ProductItem : composant permettant d'afficher un produit du colis alimentaire avec son icône, son nom, sa quantité et son unité.

ColisAlimentaire : composant regroupant la liste des produits d'un colis alimentaire ainsi que le bouton permettant d'ajouter un nouveau produit.

QuantitySelector : composant permettant d'augmenter ou de diminuer une quantité à l'aide de boutons "+" et "-".

ConfirmationCheckbox : composant permettant à l'utilisateur de confirmer une action via une case à cocher accompagnée d'un libellé.

PhotoSelection : composant permettant de sélectionner une photo parmi les photos disponibles.

PhotoOption : composant représentant une option d'action liée à une photo (prendre une photo, sélectionner une photo, etc.).

NavigationHeader :  Composant d'en-tête de navigation affichant un titre et une action (Ajouter, Modifier ou Enregistrer) selon le contexte de la page.

StockPopup : composant popup permettant de consulter le stock des produits nutritionnels, d'afficher leurs quantités disponibles et d'accéder à la modification des seuils d'alertes nutritionnelles.

EditStockPopup : composant popup permettant de modifier les seuils d'alertes nutritionnelles des produits en saisissant de nouvelles valeurs et en les enregistrant.

VDZstatutFilter : utiliser pour filtrer annule et active dans historique de zakat distribution ou ien visite .

Statufilter : filtre dans la page coordinateur et donateur 

PopupimportDonateur : c'est le pop up pour importer un fichier donateur 

Popupimportresult : c'est le pop up qui affiche les resultat de l'import 

DateSelect : utiliser comme choicecontainer mais ici on selectionne une date depuis la calendrier .

MesureInput : utiliser dans page  ajouter visite pour entrer les mesures comme poids taille ...ect 

PopupHistoriquevisite : pour voir l'historique des visites dans la page ajouter une visite

PopupHistoriqueDistribution : pour voir l'historique des distributions dans la page ajouter une disribution 

PopupDistributionfamille: pour voir les distributions d'une famille depuis la fiche famille 

Popupvisitefamille: pour voir les visites d'une famille depuis la fiche famille 

PopupdetailsDistributions : pour voir les datails d'une distribution donc quand on clique sur la carte distribution de la famille "fiche famille " on
voit les details de cette disribution meme qaund on clique sur la carte distribution dans la page liste disributions 

Popupdetailvisite : pour voir les datails d'une visite donc quand on clique sur la carte visite de la famille "fiche famille " on
voit les details de cette visite meme qaund on clique sur la carte visite dans la page liste visites.


PopupdetailsDistributionModifier : on cliquant sur le boutton modifier du pop up details distribution on peut modifier les informations d'une disribution

PopupdetailvisiteModifier : on cliquant sur le boutton modifier du pop up details visite on peut modifier les informations d'une visite

PopupMas : utiliser dans dashbord pour voir les alertes avec l'etar Mas 

Popupvisiteretard : utiliser dans dashbord pour voir les visites retard 

Popupdistributions : utiliser dans dashbord pour afficher les distributions d'un mois 

-- Galerie Page --

GalleryHeader : composant d'en-tête de la page Galerie permettant d'afficher le titre de la page, une barre de recherche et le bouton d'ajout d'une nouvelle photo.

GalleryFilters : composant contenant les filtres permettant d'afficher les photos selon leur statut (Toutes, Validées, En attente, Refusées).

GalleryGrid : composant affichant la galerie sous forme d'une grille responsive de cartes photos.

GalleryCard : composant représentant une photo dans la galerie avec son aperçu, son titre et son statut. Un clic sur la carte ouvre la fenêtre correspondante selon le statut de la photo.

StatusBadge : composant permettant d'afficher le statut d'une photo (Validée, En attente, Refusée) avec son icône et son style associé.
